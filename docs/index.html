A tiny, fast text editor for engineering work

The everyday Notepad++ feature set in a single Windows program of about 1 MB, with a CSV grid that pastes into Excel as real columns, side-by-side revision compare, live co-editing over the office network and files up to a gigabyte.

Revision compare

See exactly what changed between Rev 0 and Rev A

Ctrl+Alt+C puts two files side by side, lines kept level, with the changed words marked inside each line.

  • Compare two tabs, a file on disk, or your unsaved edits against the saved file
  • F7 jumps to the next difference; the scrollbar shows them all
  • Ignore whitespace or letter case to hide cosmetic changes
CSV grid

Registers and line lists as a real table

CSV and TSV files open as a grid you can filter, sort and edit in place, and copying to Excel lands in separate columns with values intact: 0012 stays 0012, 1-2 never becomes a date.

  • A filter under every column: text, =exact, !exclude, >100
  • Numbers sort as numbers; quoted commas and inch marks read correctly
  • A million rows open in about a second
Team, with nothing to set up

Work on the same file at the same time

Slates on the office network find each other by themselves. You see who is online, who has a file open, and you can co-edit it live with everyone's named cursor and selection.

  • Warnings when someone else has unsaved changes; edit locks
  • If the person hosting a session leaves, it carries on with the others; nothing typed is lost
  • Undo takes back only your own changes
  • A shared library of snippets, macros and find / replace presets
  • Instant search across project folders through one always-on PC
Big files

Gigabyte logs and exports, without the wait

A big file shows its first screen at once while the rest streams in. Plain-text search runs through a gigabyte in about a second, and saving runs in the background.

  • Follow mode (Ctrl+Shift+W) shows a log's new lines as they are written
  • Memory stays close to the size of the file
Looks the part

Light and dark, quiet and quick

Every pixel is drawn with Direct2D: smooth scrolling, gliding tabs, file-type badges, seven accent colours, and an optional translucent window. Nothing animates unless it moves, so an idle Slate uses no CPU at all.

  • An AI assistant panel, ready for your company's own AI server (nothing is sent anywhere until one is set)

And everything you expect from an editor

Familiar Notepad++ shortcuts, and a command palette (Ctrl+Shift+P) that lists every command with its key.

Editing

Multiple carets, column selection, macros, sort and de-duplicate lines, case changes, comment toggling, bookmarks, folding.

Search

Find and replace with regular expressions, find in files, go to line, same-word highlighting.

Files

Sessions that restore unsaved text after a crash, UTF-8 / UTF-16 / ANSI, CRLF / LF kept on save, split view, 21 syntax colourings.

Questions

Do I need admin rights?

No. The installer puts Slate in your user folder. A portable zip is available too.

How does it update?

Slate checks for a new release now and then, shows an "Update" button, and installs it in place. Each release is signed; if a new version fails to start, Slate puts the previous one back.

What do the team features need?

Nothing to set up: Slates on the same network find each other. The first time, Windows may ask whether Slate may use the network; allowing it on private networks lets others connect to you (if it is not allowed, you can still connect to them). Instant search needs one always-on PC to run slate.exe --hub <folders>.

Does anything leave the office?

No. Team features talk only to other Slates on your network, and the AI assistant only to the AI server your company sets. The only outside connection is the update check to GitHub, which can be turned off.

Plugins?

No plugin system, by design: Slate stays small, fast and predictable.
